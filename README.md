# Excavalia Canarias — Calculadora de precios

Calculadora interna de precios de transporte para Excavalia Canarias (camiones, transportes y excavaciones).

## Stack

- **Frontend**: React (Vite), desplegado en GitHub Pages
- **Backend**: Google Apps Script, expuesto como API (`doGet`/`doPost`)
- **Base de datos**: Google Sheets (tarifas por tipo de transporte, configuración)
- **Rutas**: OpenStreetMap (Leaflet) + OpenRouteService (distancia, tiempo y desnivel)
